帝国时代4 炼狱模式 天赋点修改器 v1.4.0
Laplace的ai站制作
==================================================

这是 Windows 单机工具的源码目录。终端用户请阅读“使用说明.txt”；
免安装分享包位于“分享版_免安装”，双击其中的 exe 即可使用。

【v1.4.0 的主要改进】
- 界面、使用帮助、诊断信息和 EXE 属性加入制作署名；
- 主界面点数输入框支持回车修改，Esc 取消扫描；
- 游戏版本只在连接到新进程时读取，减少后台重复文件读取；
- 输入有误时自动选中对应输入框，便于直接改正；
- 一键写入成功后清除旧手动扫描结果，避免沿用过期数值。

【v1.3.0 的主要改进】
- 精简主界面：当前点数、目标点数和“一键修改天赋点”按钮；
- 启动后自动检测游戏，目标点数默认 33875；
- 常规一键流程不再要求勾选确认或重复点击确认弹窗；
- 进度、成功和失败直接显示在主界面，扫描期间可以取消；
- 手动扫描、备份恢复、诊断收进“更多工具”窗口；
- 保留原有内存定位、写前验证、回读与备份保护。

【v1.2.0 的主要改进】
- 新增“恢复最近备份”：校验清单、确认游戏退出、先另存当前存档，
  多文件恢复失败时尝试自动回滚；
- 显示目标游戏文件版本，便于发现更新后的兼容问题；
- 新增不含路径、点数和内存地址的可复制售后诊断；
- 重新组织界面，把推荐操作、备用手动筛选和备份工具分开；
- 扫描/写入期间锁定互相冲突的按钮，写入阶段不再显示“取消扫描”。

【v1.1.0 已有的安全机制】
- 当前点数默认留空，当前/目标点数强制限制在支持范围内；
- 扫描默认只使用整数，不再把浮点近似值当成候选；
- 首次扫描结果禁止直接写入，必须在点数变化后再次验证；
- 一键模式只接受结构验证结果，不再回退到普通匹配地址；
- 候选地址最多 4 个，限制同时存在于界面和底层写入边界；
- 写入前验证私有可写内存和旧值，写后回读，失败自动尝试回滚；
- 扫描只申请读取权限，真正写入时才申请写权限；
- 写入前自动备份本地和云端 rogue_mode.rlc，并记录 SHA256 清单；
- 支持取消扫描、进程切换失效保护和扫描结果内存上限；
- 新增版本信息、DPI 清单、自动测试和打包脚本。

【开发与验证】
要求：Windows、Python 3.10+。打包需要 PyInstaller 6.x。

运行全部测试：
  python -m unittest discover -s tests -v

运行源码自检（不会打开游戏，也不会修改游戏进程）：
  python AoE4_RogueTalentTool.py --self-test

运行界面启动冒烟（创建隐藏窗口后立即关闭）：
  python AoE4_RogueTalentTool.py --smoke-test

重新打包：
  powershell -ExecutionPolicy Bypass -File .\build_release.ps1

打包脚本会生成 release\AoE4_RogueTalentTool.exe，并执行内置自检。
程序使用 asInvoker 权限，不会主动要求管理员权限；若游戏本身以管理员
身份启动，工具也需要使用相同权限运行。

【已知边界】
- 这是未购买代码签名证书的个人工具，Windows 可能显示 SmartScreen 提示；
- 游戏更新可能改变内存布局。工具会尽量“验证失败即拒绝写入”，但仍应
  只用于单人 PVE，并保留自动备份；
- 本工具不修改游戏文件，也不承诺兼容所有游戏版本。
